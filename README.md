# MMQFS

**Marlborough College Mathematics and Quantitative Finance Society**

A student-run society for people interested in markets, quantitative problem solving, and the mathematics behind both. No prior finance experience needed.

## What we do

- **Puzzles:** Jane Street puzzles and other quantitative brainteasers, written up so the reasoning is reusable.
- **Trading games:** Figgie, estimation and betting, and other games that teach pricing and probability.
- **Chess:** internal tournaments.
- **Stock pitches:** members research a company and present a thesis.
- **Talks:** guest speakers from industry through the College's alumni network.
- **Tools:** code written by members, such as backtests, scrapers and pricing models.
- **Competitions:** we enter the Wharton Global High School Investment Competition.
- **Leaderboard:** standings for contributions across all of the above.

## When we meet

Open session on **Thursdays at 17:00**. Everyone is welcome.

## How to join

Ask any member, or come to a session.

## Repository layout

| Folder | Contents |
|---|---|
| `puzzles/` | Puzzle write-ups, one file per puzzle |
| `leaderboard/` | Points data, rules and the current standings |
| `scripts/` | Privacy check used by contributors |

Want to add something? Start with [CONTRIBUTING.md](CONTRIBUTING.md). The current standings are in [leaderboard/LEADERBOARD.md](leaderboard/LEADERBOARD.md).

## Privacy

Members are named by first name and last initial only. We never publish email addresses, dates of birth or personal details.
